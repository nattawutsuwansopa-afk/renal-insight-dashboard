# Renal Insight — แดชบอร์ดผู้ป่วยไตเทียม

แดชบอร์ดภาษาไทยพร้อมกราฟวงกลม แยกช่วงอายุ และจัดการข้อมูลผู้ป่วย ใช้งานได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## เปิดใช้งานทันที

เปิด `index.html` ด้วย Chrome หรือ Edge ไม่ต้องติดตั้งแพ็กเกจหรือผ่าน ChatGPT

## อัปโหลดขึ้น GitHub

1. แตกไฟล์ ZIP นี้
2. สร้าง repository แบบ **Private** หากเก็บข้อมูลผู้ป่วยจริง
3. เลือก **Add file → Upload files** แล้วอัปโหลดไฟล์ภายในโฟลเดอร์ โดยให้ `index.html` อยู่ที่ราก repository
4. Commit changes

## เปิดเป็นเว็บไซต์ด้วย GitHub Pages

สำหรับข้อมูลสาธิตหรือข้อมูลที่ผ่านการลบตัวระบุแล้วเท่านั้น: ไปที่ **Settings → Pages → Build and deployment → Deploy from a branch** เลือก `main` และ `/(root)` แล้ว Save ทั้งนี้ความพร้อมใช้งานและการควบคุมผู้เข้าชมขึ้นอยู่กับบัญชีและการตั้งค่า GitHub

**เวอร์ชันนี้เริ่มด้วยข้อมูลว่าง ไม่มีข้อมูลผู้ป่วยตัวอย่างฝังอยู่ในไฟล์** ข้อมูลที่ผู้ใช้เพิ่มอาจมี HN และข้อมูลสุขภาพ อย่าเปิด repository หรือเว็บไซต์ให้เป็นสาธารณะก่อนนำข้อมูลดังกล่าวออก การตั้ง repository เป็น Private เพียงอย่างเดียวไม่ได้หมายความว่าเว็บไซต์ Pages จะจำกัดผู้เข้าชมตามไปด้วย

หากต้องการสร้างสำเนาสาธิตที่ไม่มีข้อมูลผู้ป่วย ใช้คำสั่ง `python3 make-demo.py` แล้วใช้ไฟล์ในโฟลเดอร์ `public-demo` สำหรับ repository/Pages สาธารณะ สคริปต์นี้ไม่แก้ข้อมูลในไฟล์ต้นฉบับ

## ความสามารถ

- กราฟโดนัทแสดงจำนวนและร้อยละ
- ช่วงอายุ: ต่ำกว่า 20, 20–39, 40–59, 60–79, 80 ปีขึ้นไป
- เพิ่ม แก้ไข ลบ และค้นหาข้อมูล
- ตัวกรองเพศและความถี่ฟอกเลือด
- พิมพ์หรือบันทึก PDF, ส่งออก CSV, สำรองและนำเข้า JSON
- ดาวน์โหลดไฟล์ HTML ที่รวมข้อมูลปัจจุบันเพื่อใช้ออฟไลน์
- เมื่อเปิดผ่านเว็บออนไลน์สำเร็จ Service Worker จะพยายามเก็บหน้าไว้สำหรับเปิดออฟไลน์ในเบราว์เซอร์ที่รองรับ หากต้องการใช้ออฟไลน์อย่างแน่นอน ให้ดาวน์โหลดไฟล์ HTML เก็บไว้ก่อน

## การเก็บข้อมูลและการซิงค์

ข้อมูลที่แก้ไขเก็บใน localStorage ของเบราว์เซอร์นั้น **ยังไม่มีฐานข้อมูลกลาง การล็อกอิน หรือการซิงค์ข้ามเครื่อง** GitHub/GitHub Pages ให้บริการไฟล์เว็บ ไม่ได้ซิงค์ข้อมูลที่ผู้ใช้กรอก หากต้องการย้ายข้อมูล ให้ส่งออก JSON แล้วนำเข้าที่อีกเครื่อง

สำรอง JSON ก่อนเปลี่ยนไฟล์ เปลี่ยนเบราว์เซอร์ เปลี่ยนโดเมน หรือล้างข้อมูลเว็บไซต์ เพราะแต่ละตำแหน่งอาจใช้พื้นที่เก็บข้อมูลแยกกัน

## แหล่งข้อมูลและข้อจำกัด

เริ่มด้วยข้อมูลว่าง ให้เพิ่มหรือนำเข้าข้อมูลจริง เกณฑ์ตัวชี้วัดเดิมยังคงอยู่ ระบบแสดงข้อผิดพลาด Kt/V ผิดคอลัมน์ไว้ให้ตรวจสอบโดยไม่ย้ายค่าเอง ไม่ใช่ระบบวินิจฉัยหรือคำสั่งรักษา

## ไฟล์

- `index.html` — ระบบทั้งหมดในไฟล์เดียว
- `sw.js` — เก็บหน้าเว็บสำหรับออฟไลน์
- `make-demo.py` — สร้างสำเนาไม่มีข้อมูลผู้ป่วยสำหรับทดลองเผยแพร่
- `.gitignore` — ป้องกันไฟล์สำรองที่มักมีข้อมูลผู้ป่วยถูกเพิ่มโดยไม่ตั้งใจ
- `.nojekyll` — ให้ Pages เสิร์ฟไฟล์ตรง ๆ

ไม่มี API key รหัสผ่าน หรือฐานข้อมูลที่เชื่อมต่ออยู่ในชุดไฟล์นี้

## รายงานพิมพ์กราฟวงกลม

ปุ่มพิมพ์ / บันทึก PDF สร้างรายงานสถิติพร้อมกราฟวงกลมแยก 5 หมวด ตามข้อมูลและตัวกรองปัจจุบัน หากอยู่หน้าทะเบียนผู้ป่วย จะเพิ่มตารางรายละเอียดผู้ป่วยท้ายรายงาน เลือก Save as PDF ในหน้าต่างพิมพ์เพื่อดาวน์โหลดรายงาน

## แนบไฟล์ Excel/PDF และแยกข้อมูล

กด **แนบ Excel / PDF** แล้วเลือกไฟล์ได้สูงสุดครั้งละ 10 ไฟล์ (ไฟล์ละไม่เกิน 20 MB, รวมไม่เกิน 5,000 แถว) ระบบอ่านในเครื่อง ไม่ส่งข้อมูลไปเซิร์ฟเวอร์ และฝังตัวอ่านไฟล์ไว้ใน HTML จึงไม่ต้องดาวน์โหลดส่วนเสริมขณะใช้งานออฟไลน์

- Excel: รองรับ .xlsx/.xls และ CSV/TSV อ่านได้หลายชีต รองรับหัวตารางไทย/อังกฤษและหัวตารางหลายแถว เลือกแถวหัวตารางและปรับการจับคู่คอลัมน์ได้
- PDF: รองรับตารางข้อความที่มี HN และหัวคอลัมน์ชัดเจน แยกข้อมูลตามตำแหน่งข้อความและหน้าของเอกสาร มีปุ่มดาวน์โหลดข้อความที่อ่านได้
- PDF แบบสแกน/รูปภาพยังต้องทำ OCR ภายนอกก่อน ตารางซับซ้อนและข้อความตัดบรรทัดต้องตรวจสอบด้วยตนเอง ไม่รับประกันว่าจะอ่าน PDF ทุกรูปแบบได้
- ระบบจับคู่ข้อมูลทั่วไป โรคประจำตัว แผนการฟอก Access, Hb, Ferritin, Ca, PO4, iPTH, Kt/V, Albumin และภาวะแทรกซ้อนเข้าหมวดเดิม แล้วคำนวณกราฟใหม่หลังยืนยัน
- ทุกแถวมีหน้าตรวจสอบ แก้ไข และเลือกแถวก่อนนำเข้า แถวที่ขาด HN หรือข้อมูลจำเป็นสำหรับผู้ป่วยใหม่จะไม่นำเข้า จนกว่าจะแก้ไขครบ
- HN เดิม: เลือกเพิ่มเฉพาะ HN ใหม่ หรือเติม/อัปเดตเฉพาะช่องที่มีค่า ช่องว่างไม่ลบค่าที่มีอยู่ หากหลายแถวมี HN เดียวกันและค่าขัดกัน ใช้ค่าจากแถวหลังสุดตามที่ระบุในหน้าตรวจสอบ
- คอลัมน์ Excel ที่ยังไม่จับคู่ เก็บเป็นรายละเอียดเพิ่มเติม พร้อมประวัติและค่าต้นฉบับจากไฟล์ เปิดได้ที่ **รายละเอียดไฟล์** ในทะเบียนผู้ป่วย การสำรอง JSON รวมข้อมูลส่วนนี้ด้วย
- แนบเก็บต้นฉบับและดาวน์โหลดคืนได้ผ่าน IndexedDB ของเบราว์เซอร์ ไฟล์ต้นฉบับ **ไม่รวม** ในสำรอง JSON หรือไฟล์ HTML ที่ดาวน์โหลด ต้องดาวน์โหลดเก็บแยกต่างหาก เบราว์เซอร์อาจไม่อนุญาต IndexedDB เมื่อเปิดไฟล์ในบางโหมด
- มีปุ่มย้อนกลับก่อนการนำเข้าไฟล์ครั้งล่าสุด ซึ่งจะแทนที่การแก้ไขที่เกิดหลังการนำเข้านั้น ควรสำรองข้อมูลก่อนใช้

ทดสอบแยก PDF ตัวอย่าง 20 ราย และตรวจเทียบ HN เพศ อายุ Mode ความถี่ และตัวเลขผลแล็บกับตารางเดิมครบถ้วน รวมถึงทดสอบหลายชีต HN ซ้ำ การรักษาช่องว่าง การแก้แถว การย้อนกลับ และการคำนวณกราฟ ยังไม่ได้ทดสอบผ่านเบราว์เซอร์จริงในรอบการเพิ่มเมนูนี้

ไลบรารีที่รวม: SheetJS CE 0.20.3 และ PDF.js 5.6.205 ดูใบอนุญาตใน THIRD_PARTY_LICENSES

## แยกข้อมูลรายวันและจัดหน้าพิมพ์

- เลือกวันที่ที่แถบด้านบน ตาราง กราฟวงกลม CSV และรายงาน PDF/พิมพ์จะใช้เฉพาะวันนั้น
- เพิ่มเมนู **สถิติแยกตามวัน** แสดงจำนวนผู้ป่วยและตัวชี้วัดรายวัน กดเปิดวันที่เพื่อดูกราฟของวันนั้นได้
- เก็บแต่ละรายการด้วย **HN + วันที่** ผู้ป่วยคนเดิมมาหลายวันได้ ข้อมูลวันใหม่ไม่เขียนทับวันก่อน
- ตัวเลือก **รวมทุกวัน** นับตามจำนวนบันทึก ผู้ป่วยคนเดิมหลายวันจะถูกนับหลายครั้งตามจำนวนวัน มีข้อความกำกับชัดเจน
- แบบฟอร์มผู้ป่วยเพิ่มช่องวันที่บันทึก/วันที่ฟอก และแสดงวันที่ในทะเบียน
- Excel/PDF จับคู่คอลัมน์วันที่ รองรับวันที่ พ.ศ./ค.ศ. เลขไทย และวันที่ Excel เมื่อไฟล์ไม่มีวันที่ ต้องเลือกวันที่สำหรับแถวที่ไม่มีวันที่ หรือระบุแยกต่อชีต/หน้า ก่อนยืนยันนำเข้า
- หลายชีตที่มี HN และวันเดียวกันรวมข้อมูลได้ โดยไม่ดึงข้อมูลของวันอื่นมาเติม
- ข้อมูลเก่าและไฟล์สำรองรุ่นเก่าที่ไม่มีวันที่อยู่กลุ่ม **ยังไม่ระบุวันที่** ไม่เดาวันที่ให้ สามารถกำหนดวันที่จริงผ่านหน้าเมนูรายวัน หรือแก้ทีละรายการ
- JSON รุ่น 2 เก็บวันที่ และยังนำเข้าสำรองรุ่น 1 ได้ รวมข้อมูลตาม HN + วัน
- ปรับหน้าพิมพ์ A4 แนวนอน ขอบกระดาษ 18 มม. และระยะภายใน เพื่อเว้นช่องว่างระหว่างกราฟ ตาราง และขอบกระดาษ พร้อมวันที่ของข้อมูลบนแต่ละหน้า ขนาดพิมพ์ยังอาจขึ้นกับการตั้งค่าเบราว์เซอร์/เครื่องพิมพ์

ตรวจสอบการแยก 2 วันของผู้ป่วยคนเดียว การอัปเดตเฉพาะวันเดิม วันที่ พ.ศ./ค.ศ. รายการที่ขาดวันที่ ตัวกรองวันที่ว่าง และวันที่ในรายงานแล้ว การเปิดหน้าตัวอย่างพิมพ์จริงในรอบนี้ถูกจำกัดโดยระบบเบราว์เซอร์ของสภาพแวดล้อม

## เริ่มใช้งานจริง · รีเซ็ตและเรียกคืน

เวอร์ชันนี้ไม่มีข้อมูลตัวอย่างฝังอยู่ในไฟล์ เมื่อเปิดครั้งแรกในเบราว์เซอร์ที่เคยใช้ระบบเดิม จะสำรองข้อมูลที่มีอยู่เป็น **ข้อมูลก่อนเริ่มใช้งานจริง** แล้วเริ่มต้นด้วยข้อมูลว่างเพียงครั้งเดียว ข้อมูลใหม่ที่เพิ่มหลังจากนั้นจะยังอยู่เมื่อเปิดระบบอีกครั้ง

- **ลบผู้ป่วย:** ย้ายรายการไปถังขยะ กด **กู้คืน** ด้านบนแล้วเลือกกู้คืนรายการได้
- **รีเซ็ตข้อมูล:** เก็บข้อมูลผู้ป่วยทั้งชุดเป็นชุดกู้คืนก่อนล้างหน้าทำงาน กู้คืนทั้งชุดได้โดยเติมเฉพาะ HN + วันที่ที่ยังไม่มี และคงรายการปัจจุบันไว้
- การลบ/รีเซ็ตจะไม่ดำเนินการ หากเก็บสำเนากู้คืนไม่ได้เนื่องจากพื้นที่ไม่พอ
- ประวัติกู้คืนไม่มีการลบอัตโนมัติ สำรอง JSON รวมข้อมูลผู้ป่วย ถังขยะ และชุดก่อนรีเซ็ต นำเข้า JSON แล้วเรียกประวัติกู้คืนกลับได้
- ถ้าเปิดไฟล์คนละตำแหน่งหรือเบราว์เซอร์คนละตัว ระบบอาจเป็นพื้นที่ข้อมูลแยกกัน สำรอง JSON จากไฟล์เดิมก่อนเปลี่ยนตำแหน่ง/เครื่อง
- การรีเซ็ตข้อมูลผู้ป่วยไม่ลบไฟล์แนบต้นฉบับ ไฟล์แนบและรูปที่ลบจะถูกย้ายไปถังขยะไฟล์แนบ กู้คืนได้ในเมนูเดียวกัน ทั้งไฟล์แนบและรูปจริงเก็บแยกใน IndexedDB และไม่รวมใน JSON/HTML สำรอง

## รองรับรูปถ่ายเอกสาร

1. กด **แนบ Excel / PDF / รูปถ่าย** หรือ **ถ่ายรูปเอกสาร** บนมือถือ
2. เลือก JPG, PNG, WebP หรือรูปแบบภาพที่เบราว์เซอร์อ่านได้ HEIC/HEIF อาจต้องแปลงเป็น JPG/PNG ในบางเบราว์เซอร์
3. ดูภาพใหญ่หรือหมุนภาพก่อนอ่าน กด **อ่านข้อความภาพ** เพื่อใช้ OCR ภาษาไทย/อังกฤษ
4. ตรวจข้อความและตาราง แก้ค่าที่อ่านผิด ระบุวันที่ และติ๊กยืนยันว่าเทียบกับภาพต้นฉบับแล้ว จึงนำเข้าได้

การแนบ/เก็บ/ดูภาพและการจัดการข้อมูลยังใช้ออฟไลน์ได้ ส่วน OCR ภาพ **ต้องใช้อินเทอร์เน็ตเพื่อโหลด worker, engine และข้อมูลภาษา** จาก CDN การประมวลผลภาพทำในเครื่อง ไม่อัปโหลดรูปไปประมวลผลบนเซิร์ฟเวอร์ ใช้ Tesseract.js 6.0.1 และ tesseract.js-core 6.0.0

OCR รองรับการช่วยอ่านตารางที่เห็นหัวคอลัมน์ HN หรือเอกสารที่ระบุหัวข้อชัดเจน เช่น HN, วันที่, อายุ, ความถี่, Hb และ Albumin ภาพเบลอ เอียง ลายมือ หรือรูปแบบตารางซับซ้อนอาจอ่านไม่ได้หรืออ่านผิด ต้องตรวจสอบทุกครั้ง และมีช่องแก้ข้อความก่อนแยกข้อมูล หากแยกอัตโนมัติไม่ได้ยังแนบเก็บและใช้ต้นฉบับกรอกข้อมูลเองได้

ทดสอบการเริ่มว่าง การเก็บชุดก่อนรีเซ็ต การกู้คืนหลังเปิดใหม่ การลบ/คืนรายการ ข้อมูลแยกรายวัน การสำรอง/นำเข้า JSON พร้อมประวัติกู้คืน และการป้องกันลบเมื่อพื้นที่ไม่พอแล้ว ทดสอบทางเดินแนบรูป–ตรวจข้อความ–ยืนยัน–นำเข้าและถังขยะไฟล์แนบโดยจำลอง OCR ไม่ได้ทดสอบความแม่นยำ OCR จริงในเบราว์เซอร์รอบนี้
